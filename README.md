# Temperature Converter GUI

A desktop application built using Python and Tkinter that converts temperatures between Celsius and Fahrenheit.

# Features
-Temperature Conversion
-Bulk Conversion
-Conversion History
-Queue-Based Processing
-Excel Export (.xlsx)
-Dark/Light Theme
-Multithreading Support
-Input Validation

# Technologies Used
-Python
-Tkinter
-Pandas
-Queue
-Threading

# How to Run
pip install -r requirements.txt
python main.py
